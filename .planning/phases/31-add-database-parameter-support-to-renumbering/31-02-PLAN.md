## Context

With HMM files now being generated by `sadie reference build` (Plan 31-01), we need to enable `Renumbering` to use custom HMM directories similar to how `Airr(database=...)` works.

**Current state:**
- `Renumbering` has no `database` parameter
- `HMMER.get_hmm_models()` uses LocalHMMBuilder → legacy ANARCI → G3 API priority
- No way to specify custom HMM location

**Target state:**
- `Renumbering(database='./my_database')` loads HMMs from `./my_database/hmms/`
- `HMMER` class accepts optional `hmm_dir` parameter for custom HMM location
- Existing behavior unchanged when `database` not specified

```python
import pytest
from pathlib import Path

def test_renumbering_with_database_parameter(tmp_path, fixture_setup):
    """Test Renumbering uses custom HMMs from database path."""
    # Create mock HMM directory structure
    hmms_dir = tmp_path / "hmms"
    hmms_dir.mkdir()
    
    # Copy or create test HMM file (use existing from germlines)
    from sadie.germlines import get_germlines_base_dir
    src_hmm = get_germlines_base_dir() / "hmms" / "human_H.hmm"
    if src_hmm.exists():
        import shutil
        shutil.copy(src_hmm, hmms_dir / "human_H.hmm")
    
    # Test with database parameter
    from sadie.renumbering import Renumbering
    renumbering = Renumbering(
        allowed_species=["human"],
        allowed_chain=["H"],
        database=tmp_path,
    )
    
    # Verify HMMs loaded from custom path
    assert renumbering.hmmer._hmm_dir == hmms_dir

def test_renumbering_database_missing_hmms_raises(tmp_path):
    """Test Renumbering raises error if hmms/ directory missing."""
    from sadie.renumbering import Renumbering
    
    with pytest.raises(FileNotFoundError, match="HMM directory not found"):
        Renumbering(database=tmp_path)

def test_renumbering_database_parameter_none():
    """Test Renumbering default behavior without database parameter."""
    from sadie.renumbering import Renumbering
    
    renumbering = Renumbering(allowed_species=["human"])
    assert renumbering.hmmer._hmm_dir is None
```
