## Context

The `sadie reference build` command creates IgBLAST databases from reference.yml configurations. To enable `Renumbering(database='./my_database')`, the build must also generate HMM files that HMMER can use for antibody numbering.

**Current state:**
- `References.make_airr_database()` creates: `Ig/blastdb/`, `Ig/internal_data/`, `aux_db/`
- `LocalHMMBuilder` in `germlines/renumbering_integration.py` has working Stockholm + HMM building logic
- Gapped AA sequences available in reference DataFrame as `imgt.sequence_gapped_aa`

**Target state:**
- Build also creates: `stockholms/{name}_{chain}.sto` and `hmms/{name}_{chain}.hmm`
- HMM files built from V and J gene gapped AA sequences per species/chain

<task id="1">
<title>Add HMM Building Method to References Class</title>
<description>
Add a `_make_hmm_files()` method to the `References` class that builds Stockholm alignment files and HMM models from the reference DataFrame.

Implementation steps:
1. Add new method `_make_hmm_files(self, outpath: Path) -> None` to `References` class
2. Create output directories: `stockholms/` and `hmms/` under outpath
3. Group reference DataFrame by name (species), then by chain type (H, K, L)
4. For each name/chain combination:
   - Filter for V and J gene segments only
   - Extract gapped AA sequences from `imgt.sequence_gapped_aa` column
   - Skip if no gapped sequences available (log warning)
   - Write Stockholm alignment file using padding and RF annotation
   - Build HMM using pyhmmer from the Stockholm file
   - Save HMM to `hmms/{name}_{chain}.hmm`

Key patterns to follow from `LocalHMMBuilder`:
```python
# Initialize pyhmmer
alphabet = pyhmmer.easel.Alphabet.amino()
builder = pyhmmer.plan7.Builder(alphabet)
background = pyhmmer.plan7.Background(alphabet)

# Write Stockholm format
lines = ["# STOCKHOLM 1.0", f"#=GF ID {name}_{chain}", ""]
for gene_name, seq in pairs:
    padded_seq = seq.ljust(max_seq_len, ".")
    lines.append(f"{gene_name.ljust(max_name_len)}  {padded_seq}")
rf_label = f"#=GC RF".ljust(max_name_len + 2)
lines.append(f"{rf_label}  {'x' * max_seq_len}")
lines.append("//")

# Build HMM
with pyhmmer.easel.MSAFile(sto_path, digital=True, alphabet=alphabet, format="stockholm") as msa_file:
    msa = next(msa_file)
    hmm, _, _ = builder.build_msa(msa, background)
```

Handle chain type extraction:
- Gene names like "IGHV1-69*01" → chain type from position 3: H, K, or L
- Filter appropriately: H for heavy, K for kappa, L for lambda
