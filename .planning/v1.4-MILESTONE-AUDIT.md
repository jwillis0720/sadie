## Tech Debt / Findings

### Finding: j_cigar Column Difference

**Phase:** 33
**Severity:** Investigation needed

The parity test detected a difference in the `j_cigar` column:

```
G3 value:        '355S9N53M'
Germlines value: '355S9N53M1N'
```

The Germlines backend appends `1N` to J gene CIGAR strings that G3 does not include.

**Action Required:** Human decision needed on which format is correct:
- Bug in Germlines (remove extra `1N`)
- Bug in G3 (should include `1N`)
- Document as expected difference

### Deviation: Human-Only Reference

The original plan specified `reference.g3.yml` but G3 backend fails to build multi-species references. Resolution: Created `reference_parity_test.yml` with human-only genes.
