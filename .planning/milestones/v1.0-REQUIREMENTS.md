## v1 Requirements

### Provider Selection

- [x] **PROV-01**: System MUST allow users to specify a germline provider (imgt, ogrdb, vdjbase, custom) when initializing AIRR analysis (FR-001) — ✅ Validated
- [x] **PROV-02**: System MUST allow users to specify a germline provider when initializing Renumbering operations (FR-002) — ✅ Validated
- [x] **PROV-03**: System MUST expose a `germline_backend` parameter accepting "g3" (default) or "germlines" (FR-003) — ✅ Validated
- [x] **PROV-04**: System MUST use default provider priority (custom > ogrdb > vdjbase > imgt) when no provider specified (FR-004) — ✅ Validated
- [x] **PROV-05**: System MUST use local germlines module data when germlines backend selected (FR-005) — ✅ Validated
- [x] **PROV-06**: System MUST apply single provider selection to all V/D/J segments within a run (FR-014) — ✅ Validated

### Error Handling

- [x] **ERR-01**: System MUST provide clear error messages when provider has no data for specified species (FR-006) — ✅ Validated
- [x] **ERR-02**: System MUST validate custom germlines at ingestion, rejecting invalid sequences with detailed errors (FR-012) — ✅ Validated
- [x] **ERR-03**: System MUST ensure gapped AA sequences available for all V/J genes in HMM building; fail with clear error if missing (FR-013) — ✅ Validated
- [x] **ERR-04**: System MUST NOT silently fall back to G3 when germlines backend fails (NFR-002) — ✅ Validated

### Backwards Compatibility

- [x] **COMPAT-01**: G3 remains default backend; germlines is opt-in via explicit parameter (FR-007) — ✅ Validated
- [x] **COMPAT-02**: Existing tests in tests/unit/airr/ continue to pass — ✅ Validated
- [x] **COMPAT-03**: Existing tests in tests/unit/renumbering/ continue to pass — ✅ Validated
- [x] **COMPAT-04**: Output format/schema identical regardless of provider (FR-011) — ✅ Validated

### Testing

- [x] **TEST-01**: New test directory tests/unit/germlines/ with mirrored AIRR tests (FR-008) — ✅ Validated
- [x] **TEST-02**: Mirrored renumbering tests using germlines backend (FR-009) — ✅ Validated
- [x] **TEST-03**: Tests verify same species/chains/segments supported as existing modules (FR-010) — ✅ Validated
- [x] **TEST-04**: Gapped AA fallback translation test when only gapped NT available — ✅ Validated

### Performance

- [x] **PERF-01**: Germline lookup performance equivalent to G3 backend (NFR-001) — ✅ Validated

## v2 Requirements (Deferred)

- Multi-provider blending per analysis (currently single provider per run)
- GUI for provider selection
- Provider-specific analytics/reporting

## Out of Scope

- T-cell receptor (TR) germlines — focus on immunoglobulin (IG) only
- Real-time provider synchronization — manual update via update_databases()
- Provider switching mid-linked-analysis consistency — user responsibility
