# Milestone v1.0: Germline Database Integration

**Status:** ✅ SHIPPED 2026-01-22
**Phases:** 1-12
**Total Plans:** 12

## Overview

Connect SADIE's germline database module to existing AIRR annotation and Renumbering modules, enabling selection of germline providers (IMGT, OGRDB, VDJbase, custom) via a `germline_backend` parameter. The integration uses a feature flag for backwards compatibility, with G3 API remaining default while local germlines is opt-in.

## Milestone Summary

**Key Decisions:**

- Feature flag approach (SADIE_USE_GERMLINES_MODULE) — enables gradual migration
- G3 format adapter — maintains Reference system compatibility
- Stockholm HMM building — matches G3 workflow for result parity
- Mirrored test suite — validates integration without modifying existing tests
- Single provider per run — prevents confusing mixed results
- CLI population command — programmatic data management

**Issues Resolved:**

- Gapped sequence loading for non-human species
- HMM generation for rabbit, chicken, and other species
- Offline operation capability
- Provider priority enforcement

**Technical Debt:**

- 3 CLI dry-run tests flaky (click runner + network timeout, not code issue)
- C gene warnings for some species (expected - not all have C genes in IMGT)
